# RST AI セミナー ハンズオン環境

ブラウザだけで、全員が同じAI開発環境を数分で立ち上げるための教材です。
**インストール作業も fork も不要です。**

---

## セットアップ（3ステップ）

### ステップ1 — 環境を起動する

このページ上部の緑の **`Code`** ボタン → **`Codespaces`** タブ → **`Create codespace on main`**

ブラウザ上に VS Code が開きます。初回は1〜3分かかります。
ターミナルに `セットアップ完了` と表示されたら次へ進んでください。

> **fork は不要です。** このリポジトリから直接作成してください。

### ステップ2 — APIキーを設定する

ターミナルに以下を貼り付けて Enter：

```bash
bash scripts/setup-key.sh && source ~/.bashrc
```

会場で共有されたキーを貼り付けて Enter を押してください。
入力内容は画面に表示されません（画面共有中でも安全です）。

### ステップ3 — 確認して開始する

```bash
npm run doctor
```

すべて `[ OK ]` になれば準備完了です。あとは起動するだけ：

```bash
claude
```

演習は **[docs/exercises.md](docs/exercises.md)** にあります。

## うまくいかないとき

まず `npm run doctor` を実行してください。原因と対処が表示されます。

| 症状 | 対処 |
|------|------|
| `claude: command not found` | `source ~/.bashrc` を実行。それでも駄目なら `npx claude` |
| `API疎通 失敗 (HTTP 401)` | キーの貼り付けミス。ステップ2をやり直す |
| `node_modules がありません` | `npm install` を実行 |
| `セットアップ完了` が出ない | ターミナルで `npm install` を手動実行 |
| Codespace が作成できない | Codespaces の無料枠切れの可能性。運営に申し出てください |
| 上記で直らない | `npm run doctor` の出力を運営に見せてください |

## この教材について

題材は**依存パッケージゼロのタスク管理API**です。
会場のネットワーク事情で `npm install` が重くならないよう、
外部ライブラリを使わない構成にしています。

```
src/server.js     HTTPサーバー
src/store.js      タスクの保管
src/validate.js   入力チェック
test/             テスト
AGENTS.md         AI向けのプロジェクト説明書
```

主なコマンド：

```bash
npm test        # テスト実行
npm start       # サーバー起動（ポート3000は自動で転送されます）
npm run doctor  # 環境診断
```

> セットアップ直後、`npm test` は **1件だけ意図的に失敗します。**
> これは演習3の教材です。故障ではありません。

## セキュリティに関する注意

- **APIキーをファイルに書いてコミットしないでください。**
  `setup-key.sh` はコンテナ内のホームディレクトリにのみ書き込み、
  リポジトリには一切残しません。
- 配布されたキーは**セミナー終了後に失効します**。持ち帰っても使用できません。
- キーを他者に共有・再配布しないでください。
