# RST AI セミナー ハンズオン

**あなたの仕事に使える小さなアプリを、AIと一緒に作ります。**

プログラミングの経験は要りません。インストール作業も fork も不要です。
このページを上から順に進めてください。

---

## 今日やること

環境が立ち上がるまでの数分で、ここを読んでおいてください。

```
  ステップ1〜4   準備をする                         約15分
       ↓
  ステップ5     AIがあなたにヒアリングして、        約15分
                作るものを一緒に決める
       ↓
  ステップ6     AIがそれを実際に作る                約30〜45分
       ↓
  ステップ7     できたものをブラウザで動かす        約5分
       ↓
  ステップ8     みんなで見せあいっこ                約10分
```

### これは「現場でシステムを作る流れ」そのものです

エンジニアが仕事でシステムを作るとき、いきなりコードは書きません。
実際にはこういう順番で進みます。

| 現場の工程 | やること | 今日は |
|---|---|---|
| ① ヒアリング | 相手が何に困っているかを聞く | **AIがやる**（ステップ5） |
| ② 要件定義 | 「何を作るか」を決める | **AIがやる**（ステップ5） |
| ③ 設計 | 画面・入力・出力を決める | **AIがやる**（ステップ6） |
| ④ 実装 | 実際に作る | **AIがやる**（ステップ6） |
| ⑤ 動作確認 | ちゃんと動くか確かめる | **あなたがやる**（ステップ7） |

つまり今日は「AIに丸投げする」のではありません。
**AIがヒアリング役・設計役・実装役をやり、あなたは発注者兼チェック役になる**、という体験です。

現場で一番むずかしいのは、実は④の実装ではなく①②の「何を作るか決める」ところです。
そこをAIと対話しながら詰めていく感覚を、まず持ち帰ってください。

# 準備

## ステップ1 — 環境を起動する

このページ上部の緑の **`Code`** ボタン → **`Codespaces`** タブ → **`Create codespace on main`**

ブラウザ上に VS Code（プログラムを書くための画面）が開きます。初回は1〜3分かかります。
下の方にあるターミナル（黒い画面）に文字が流れ終わるまで待ってください。

> **fork は不要です。** このリポジトリから直接作成してください。

待っている間に、上の「今日やること」を読んでおいてください。

## ステップ2 — APIキーを設定する

ターミナルに以下を貼り付けて Enter：

```bash
bash scripts/setup-key.sh && source ~/.bashrc
```

会場で共有されたキーを貼り付けて Enter を押してください。
**入力しても画面には何も表示されませんが、正常です**（画面共有中でも安全なようにしています）。

## ステップ3 — 準備ができたか確認する

```bash
npm run doctor
```

すべて `[ OK ]` になれば準備完了です。
`[ NG ]` が出たら、画面に出ている `→` の指示に従ってください。

## ステップ4 — Claude を起動する（★つまずきポイント）

```bash
claude
```

**初回だけ、いくつか質問されます。** ここで違う方を選ぶと先に進めなくなるので、
下の表のとおりに選んでください。（順番は前後することがあります）

| 聞かれること | 画面の見た目 | **選ぶもの** |
|---|---|---|
| APIキーを使うか | `API key` `Detected` などの英語と、選択肢が2つ | **「使う（Yes / Use this key）」側** |
| 画面の色 | `Dark mode` `Light mode` などの一覧 | どれでもOK（見やすい方） |
| このフォルダを信頼するか | `Do you trust the files...` | **「信頼する（Yes, I trust）」側** |
| キーボード設定 | `Shift+Enter` の話 | どれでもOK |

操作方法：**↑↓キーで選んで、Enter で決定**します。マウスは使いません。

### ✅ うまくいったサイン

`>` のような入力欄が出て、日本語を打てる状態になったら成功です。

### ❌ 間違えたサイン

こうなったら、選択を間違えています。

- **ブラウザでログイン画面／サインイン画面が開いた**
- `Please log in` `Sign in to Claude` のような英語が出て先に進めない
- いつまでも認証を求められる

### 🔧 やり直す方法

あわてなくて大丈夫です。**何度でもやり直せます。**

まず `Ctrl` を押しながら `C` を2回押して、Claude を終了します。
そのあと、次の1行をターミナルに貼り付けて Enter：

```bash
bash scripts/reset-claude.sh
```

最後に、もう一度：

```bash
claude
```

またステップ4の最初の質問から始まります。今度は上の表のとおりに選んでください。

> APIキーは消えないので、ステップ2をやり直す必要はありません。

# 本編

## ステップ5 — AIにヒアリングしてもらい、作るものを決める

Claude の入力欄に、次のとおり入力して Enter：

```
/work-idea-hearing
```

> スラッシュコマンドがうまく出てこない場合は、
> 「自分の仕事に活かせるアプリのアイデアを考えたい」と日本語で打っても始まります。

### ここで何が起きるか

AIがあなたに**質問をしてきます**。1問ずつ、順番に答えてください。
専門用語は出てきません。ふだんの言葉で答えて大丈夫です。

1. **お仕事・部署は？** — 営業、総務、経理、企画、サポートなど
2. **時間がかかる・面倒だと感じる作業は？** — できれば具体的なエピソードを1つ
3. **その作業で今使っているものは？** — Excel、メール、LINE、紙、口頭 など
4. **その作業で関わる相手は？** — 同僚、上司、取引先、お客さま など

そのあと、AIが「こういうことですね」と**内容をまとめて確認**してきます。
違っていたら遠慮なく直してください。ここがズレると、あとで作るものもズレます。

最後に、あなた専用の**アイデアを3〜5個**出してくれます。それぞれに

- 名前
- 何をするか
- なぜあなたの役に立つか
- どれくらいの規模か

が書かれています。この中から **1つ選んでください。**

> 💡 迷ったら「一番よく使いそうなもの」を選ぶのがおすすめです。
> 思いつかない・答えにくいときは、正直にそう言えばAIがヒントを出してくれます。

## ステップ6 — AIに作ってもらう

アイデアが決まったら、次のとおり入力して Enter：

```
/vibe-app-builder
```

> こちらも「これを実際に作って」と日本語で打ってもOKです。

### ここで何が起きるか

1. **見た目の好みを2〜3問聞かれます**
   「きちんとした感じ／ポップで楽しい感じ／シックで落ち着いた感じ」など。
   こだわりがなければ「おまかせで」と答えて大丈夫です。
2. **AIが「こんな感じで作ります」と方針を伝えてきます**
3. **AIが実際にファイルを作ります**
   数分かかります。画面に文字がたくさん流れますが、**読まなくて大丈夫です。**
   できあがったファイルは `apps/` フォルダに入ります。

> **「〜してもいいですか？」と許可を聞かれたら**、内容をざっと見て
> 問題なさそうなら「はい」を選んでください（↑↓キー＋Enter）。

## ステップ7 — ブラウザで動かしてみる

**新しいターミナルを開いてください。**
（ターミナルの右上にある `+` のアイコンを押すと、もう1つ増えます。
Claude は元のターミナルで動かしたままにしておきます）

新しいターミナルに、次を貼り付けて Enter：

```bash
python3 preview.py
```

すると画面の**右下に通知**が出るので、**「ブラウザーで開く」**を押してください。
新しいタブであなたのアプリが開きます。

> **なぜこの操作が必要なの？**
> 今あなたが使っている VS Code は、自分のパソコンではなく
> **クラウド上のコンピューター**の中で動いています。
> なので、できたファイルをダブルクリックしても自分のブラウザでは開けません。
> `preview.py` は「クラウド側にウェブサイトを立てて、自分のブラウザから
> 見られるようにする」ためのものです。

**通知が消えてしまったら**：画面下の **「ポート」** タブを開き、
`3000` の行にある地球儀のアイコンを押しても開けます。

### 直してほしいところが出てきたら

Claude を動かしているターミナルに戻って、そのまま日本語で伝えてください。

```
ボタンの色をもう少し明るくして
```
```
入力欄をもう1つ増やして、そこにも日付を入れられるようにして
```

直したら、ブラウザのタブを**再読み込み**すれば反映されます。
（`preview.py` は動かしたままで大丈夫です）

## ステップ8 — 見せあいっこ

できたものをお互いに見せてください。

- 何を作ったか
- どこが一番役に立ちそうか
- AIとのやりとりで「おっ」と思ったこと

うまく動かなかった人も、**どこで詰まったかを共有するのが一番価値があります。**

## うまくいかないとき

まず `npm run doctor` を実行してください。原因と対処が表示されます。

### 準備でつまずいたとき

| 症状 | 対処 |
|------|------|
| `claude: command not found` | `source ~/.bashrc` を実行。それでも駄目なら `npx claude` |
| `API疎通 失敗 (HTTP 401)` | キーの貼り付けミス。ステップ2をやり直す |
| `node_modules がありません` | `npm install` を実行 |
| Codespace が作成できない | Codespaces の無料枠切れの可能性。運営に申し出てください |

### Claude でつまずいたとき

| 症状 | 対処 |
|------|------|
| ブラウザでログイン画面が出た | ステップ4の「やり直す方法」へ |
| 初回の質問で選択を間違えた | 同上 |
| モデルが `sonnet` から変えられない | **仕様です。**このセミナー用の設定なのでそのまま進めてください |
| 反応がおかしい・話が噛み合わない | `/clear` と入力して会話をリセット |
| AIが延々と喋り続ける | `Esc` キーで止められます |

### プレビューでつまずいたとき

| 症状 | 対処 |
|------|------|
| 「ポート 3000 は既に使われています」 | 別のターミナルで既に動いています。そのタブに戻ってください |
| 右下の通知が出ない／消えた | 画面下の「ポート」タブ →`3000` の地球儀アイコン |
| ブラウザに「apps/ にまだHTMLがありません」と出る | ステップ6がまだ終わっていません。Claude の画面に戻ってください |
| 真っ白な画面が出る | URL の末尾にファイル名が付いているか確認。付いていなければ一覧に戻る |

上記で直らないときは、**画面をそのままにして運営に声をかけてください。**

## セキュリティに関する注意

- **APIキーをファイルに書いてコミットしないでください。**
  `setup-key.sh` はコンテナ内のホームディレクトリにのみ書き込み、
  リポジトリには一切残しません。
- 配布されたキーは**セミナー終了後に失効します**。持ち帰っても使用できません。
- キーを他者に共有・再配布しないでください。

## 終わったら

Codespace は不要になったら削除してください（[github.com/codespaces](https://github.com/codespaces) から削除できます）。

作ったファイルを持ち帰りたい場合は、`apps/` の中のファイルを
右クリック →「ダウンロード」で自分のパソコンに保存できます。
**HTMLファイル1枚で動く**ので、持ち帰ってダブルクリックすればそのまま使えます。
