# アイデアカタログ（職種別）

ヒアリング結果をもとにアイデアを考えるときの参考カタログ。ここに書かれたアイデアをそのまま提示するのではなく、参加者の状況（相手、頻度、使っているツールなど）に合わせて言い換えてから提案すること。

すべて「Claude Code + GitHub Codespaceで15〜45分程度で試作できる」規模のものに絞っている。大規模なシステムや外部サービスとの本格連携が前提のアイデアはここには含めない。

## カテゴリ1: 定型文章・メール作成系

対象になりやすい職種: 営業、事務、カスタマーサポート、総務

- 催促メール作成ツール: 状況（相手・期日・トーン）を入力すると、角の立たない催促メール文面を作る簡易フォーム
- 議事録・ToDo抽出ツール: 会議メモのテキストを貼り付けると、要点とToDoリストに整形する
- お詫びメールジェネレーター: 状況をいくつか選ぶだけで、丁寧なお詫び文を生成する

## カテゴリ2: 企画・アイデア出し系

対象になりやすい職種: 企画、マーケティング、営業推進、広報

- ダメ出しシミュレーター: 自分の企画文を入力すると、「厳しい上司」「Z世代顧客」など複数の視点からツッコミがもらえる
- アイデア量産ツール: テーマを入れると、突飛なアイデアを大量に出してくれる壁打ち相手
- 企画の弱点診断ツール: 企画文を入力すると、弱点や抜け漏れを指摘してくれる

## カテゴリ3: 職場コミュニケーション系

対象になりやすい職種: マネージャー、チームリーダー、対人業務全般

- トーン変換ツール: 感情的になった文章を入力すると、冷静で建設的な文章に変換する
- 依頼文クッション言葉ジェネレーター: 面倒な依頼文を、角が立たない言い回しに変換する

## カテゴリ4: データ・エクセル系

対象になりやすい職種: 営業、バックオフィス、店舗管理

- 売上データかんたん分析ツール: 数字を貼り付けると、改善点をいくつか教えてくれる
- 経費・レシート集計フォーム: 入力したデータを自動で集計・グラフ化する簡易画面

## カテゴリ5: キャリア・自己紹介系

対象になりやすい職種: 全職種（特に異動・転職を考えている人）

- 強み発掘ツール: 日々の業務を箇条書きで入力すると、市場で評価されそうな強みを言語化する
- 自己紹介文ジェネレーター: 経歴を入力すると、用途別（名刺交換用、社内紹介用など）の自己紹介文を作る

## カテゴリ6: 記録・管理系

対象になりやすい職種: 総務、事務、店舗・現場管理

- 簡易チェックリスト/日報フォーム: 毎日入力する項目をフォーム化し、記録を貯めていく
- 締切・リマインダー管理ツール: 締切と内容を入れておくと一覧表示してくれる
